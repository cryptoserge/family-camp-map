# キャンプ場マップ

家族でキャンプ場を地図・一覧・3件比較から探す、GitHub Pages向け静的サイト。

- 346項目：候補102 / 条件付き28 / 情報不足196 / 対象外7 / 休廃業・関連13
- 331項目に施設出典付き位置情報。候補102件は全件掲載。位置未確認15件は一覧に保持。
- 訪問済み4施設はマークのみ公開。家族の名前・自宅・旅行予定・予約情報は含めません。
- 区画サイト・フリーサイトは「使う区画」を基準に分類し、不明なものは未確認。
- `#compare=C001%2CC107%2CC324` の形式で最大3件を共有。自動同期・ログインなし。

## 実行・更新

Node.js 22以降で `npm ci` → `npm test` → `npm run build`。
`dist/` を静的HTTPサーバーで開きます（例：`python3 -m http.server 4173 --directory dist`）。

公開用正本は `public/camps.json`。調査の正本CSVはローカルに保持し、このリポジトリにはコピーしません。
CSVからの再生成は `python3 scripts/build-data.py <正本CSV> <施設IDをキーとする座標補足JSON>`。
座標補足には `status, lat, lng, source, checked, reason` を記録します。
確認日は資料を確認した日付に合わせて更新します。再生成後に件数・公開対象項目・訪問マークを確認してください。

`main` への更新をGitHub Actionsが検証・ビルドしGitHub Pagesに配信します。

## データの意味

家族5人とランドロックの一次判定です。約100㎡以上を広さの目安とし、面積公表のないフリーサイトも根拠があるものは候補に含みます。日程・空き・電源は判定に使用していません。
住所・施設条件・位置の出典と確認日は施設詳細に掲載。位置は施設が掲載した案内点または公式掲載図の概略位置であり、テント区画や車の入口を保証するものではありません。位置未確認の施設に仮の座標を付けません。
